# Support

**Customer support:** support@primodel.io

Please use email rather than GitHub issues. Primodel runs on your own infrastructure, so a support
question usually involves details about your deployment that do not belong in a public tracker.

Useful things to include: the Primodel version (the in-app support dialog and `/api/app-info` both report
it), how it is deployed, and what you expected to happen.

**Security vulnerabilities do not go here** — see [SECURITY.md](SECURITY.md). A vulnerability report sent
to support is a vulnerability report sitting in the wrong queue.

**Documentation:** [primodel.io](https://primodel.io) · **Deployment recipes:**
[get-started](https://github.com/primodel/get-started)
